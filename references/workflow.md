# 大V观点分析详细工作流参考

## 完整流程

```
用户输入言论 → db_save.py 保存（精确到分钟，含仓位）
    → db_sync.py 自动同步 JSON 到数据库（幂等，去重）  ← 每次分析第一步
    → db_query.py --kol-name "大V" --json（默认最近30天）
    → 提取最新观点 + 仓位变化曲线 + 观点演化轨迹 + 标的
    → 并行查询 8 个数据维度（Skill 工具）
    → 交叉验证（最新观点权重最高） → 评分 → 生成 HTML 报告
```

## 时间优先原则（CRITICAL）

1. **存储精度**：每条记录 `record_date` 精确到分钟（`YYYY-MM-DD HH:MM`）
2. **查询默认**：所有查询默认 `ORDER BY record_date DESC`（最新在前）
3. **分析权重**：最新 1-3 天的观点权重占 70%，历史观点占 30%
4. **观点演化**：大V可能在同一天内多次修正观点，每次修正单独记录
5. **持仓追踪**：追踪大V的持仓变化（几米→加仓→兑现），这是验证可信度的关键指标

示例：wu2198 8/3~8/5 观点演化轨迹
- 8/3 09:26：大盘3800争夺，构筑B反弹，第四浪调整未变
- 8/3 15:10：收3809，需收复3856突破3886确立B反
- 8/4 10:59：买进1米SoC，📊 **持仓6米** → 加仓
- 8/4 15:11：收复3486，B反弹结构明朗
- 8/5 09:55：兑现1米存储芯片，📊 **持仓5米** → 开始减仓
- 8/5 14:10：兑现2米（滞涨科技+SoC），📊 **持仓仅3米** → 大幅减仓
- 8/5 14:40：关注电池材料板块 → 调仓方向

## 仓位追踪（新增 CRITICAL）

大V的仓位变化（position_size + position_action）是比言论更重要的信号。

仓位字段：
- `position_size`：整数，大V的"米"数（1米 ≈ 10%仓位）
- `position_action`：加仓 / 减仓 / 兑现 / 持有 / 建仓 / 清仓
- `position_note`：补充说明（加仓什么、减仓原因、调仓方向）

分析时优先检查仓位曲线：
```
6米(8/4) → 5米(8/5早) → 3米(8/5午)
```
仓位连续下降 + 嘴上说"B反没走完" = 边涨边兑现 → 警惕追高风险

仓位查询示例：
```bash
python <skill-dir>/scripts/db_query.py --kol-name "wu2198" --latest 20 --json
# 在 JSON 输出中查找 position_size 不为 null 的记录
```

## 观点提取指南

从大V言论中识别：

### 方向判断
- **看多信号**：看好、牛市、暴涨、抄底、低估、黄金坑、政策利好、资金涌入
- **看空信号**：看空、熊市、暴跌、逃顶、高估、泡沫、政策打压、资金出逃
- **中性信号**：震荡、观望、结构性行情、分化、轮动

### 标的识别
- 板块指数：沪深300、中证500、创业板、科创板、恒生科技等
- 行业：新能源、半导体、消费、医药、银行、地产、AI、军工等
- 具体 ETF：如 510300（沪深300ETF）、159915（创业板ETF）等
- 风格：大盘/小盘、价值/成长、红利/高股息

## 数据查询优先级

**第零步（新增）：先加载大V最新观点 + 仓位曲线**
```bash
# 默认最近30天
python <skill-dir>/scripts/db_query.py --kol-name "大V名称" --json

# 单独查仓位变化曲线
python <skill-dir>/scripts/db_query.py --kol-name "大V名称" --with-position --json
```

然后按与观点相关度排序查询：
1. 先查最新观点直接涉及的指数/行业数据
2. 再查全市场宏观背景
3. 最后查情绪面和机构观点

## 评分规则

可信度评分 = 各维度加权平均（时间优先，最新观点权重最高）：

| 维度 | 权重 | 评分依据 |
|------|------|---------|
| 行情方向一致性 | 20% | 最新观点方向与近期行情趋势是否一致 |
| 观点演化准确性 | 20% | 大V在时间轴上的预判是否逐步兑现（如点位预测→实际到达） |
| 基本面支撑 | 20% | PE/PB 估值分位是否支持观点 |
| 情绪面共振 | 10% | 舆情、研报是否与观点共振 |
| 资金面验证 | 10% | 主力资金流向是否支持观点 |
| 技术指标 | 10% | MACD/RSI/均线等技术信号 |
| 逻辑自洽性 | 10% | 观点内部逻辑是否自洽，调仓是否合理 |

**新增「观点演化准确性」维度**：追踪大V在时间轴上的预判准确度。例如：
- wu2198 预测「3160→3486→3590」，实际「3158→3488→3535」→ 高度准确
- 持仓从6米→5米→3米，边涨边卖 → 操作纪律良好
