# 五色青龙量化分析体系参考手册

> 本手册详细描述了五色青龙量价系统、黄金分割、波浪理论、89日均线、筹码集中度及WR威廉指标的分析方法与参数。

---

## 一、五色青龙量价体系

五色青龙是一种基于量价关系的趋势识别系统，通过五种颜色标记不同的市场状态，核心逻辑是"量在价先、量价配合"。

### 颜色信号定义

| 颜色 | 量价状态 | 含义 | 操作倾向 |
|------|---------|------|---------|
| 🔴 **赤红** | 放量上涨 | 主力资金强力介入，强势突破 | 积极做多 / 加仓 |
| 🟠 **橙色** | 缩量上涨 | 惜售拉升，稳定上行 | 持仓观望 / 谨慎加仓 |
| 🟡 **黄色** | 放量下跌 | 恐慌抛售或主力出逃 | 减仓 / 止损 |
| 🟢 **绿色** | 缩量下跌 | 交投清淡，自然回调 | 观望 / 等信号 |
| ⚪ **白色** | 量价平衡 | 横盘整理，方向不明 | 持币观望 |

### 判定规则

以当日及近5日均量（MA5-Vol）和当日涨跌幅为基础：

1. **放量 vs 缩量**：当日成交量 > 近5日均量 × 1.2 → 放量；当日成交量 < 近5日均量 × 0.8 → 缩量；其余为正常量。
2. **上涨 vs 下跌**：当日收盘价 > 前日收盘价 → 上涨；反之下跌。
3. **横盘判定**：连续5个交易日涨跌幅绝对值均 < 1% → 白色信号。
4. **信号有效确认**：连续2天出现同一颜色信号，确认为有效信号。

### 辅助指标

- **量比** = 当日成交量 / 近5日均量
- **青龙线**：13日EMA与21日EMA的金叉/死叉作为趋势确认
- **五色连续天数**：跟踪当前颜色持续的天数，判断趋势强度

## 二、黄金分割（斐波那契）

### 回调位

选取近期显著的高点和低点，计算斐波那契回调位：

| 级别 | 比例 | 用途 |
|------|------|------|
| 浅回调 | 23.6% | 极强势回调支撑 |
| 标准回调 | 38.2% | 强势回调支撑 |
| 半程回调 | 50.0% | 中性回调支撑 |
| 深回调 | 61.8% | 标准回调支撑（最重要） |
| 极限回调 | 78.6% | 趋势终结预警线 |

### 扩展位（用于测算目标位）

| 级别 | 比例 | 用途 |
|------|------|------|
| 第一目标 | 127.2% | 保守目标 |
| 第二目标 | 161.8% | 标准目标（黄金比例） |
| 第三目标 | 200.0% | 激进目标 |
| 极限目标 | 261.8% | 极端行情目标 |

### 使用方法

1. 确定趋势方向（上涨趋势用回调做多，下跌趋势用反弹做空）
2. 选取波段起点（最低点）和终点（最高点）
3. 计算并绘制回调位和扩展位
4. 结合五色青龙颜色信号确认入场时机

## 三、波浪理论（艾略特波浪）

### 基本结构

- **推动浪**：1-2-3-4-5，方向与主趋势一致
- **调整浪**：A-B-C，方向与主趋势相反

### 浪级关系（斐波那契比例约束）

| 关系 | 常见比例 | 说明 |
|------|---------|------|
| 浪2回调浪1 | 50% / 61.8% | 浪2不应跌破浪1起点 |
| 浪3长度 | 浪1 × 1.618 / 2.618 | 浪3通常是最长的推动浪 |
| 浪4回调浪3 | 23.6% / 38.2% | 浪4不进入浪1区域 |
| 浪5长度 | 浪1 × 1.0 / 浪1→3 × 0.618 | 浪5可能衰竭 |

### 计数规则

1. 浪2永远不能回撤超过浪1的100%
2. 浪3永远不是最短的推动浪
3. 浪4不能与浪1的价格区间重叠（重叠视为调整浪的一部分）
4. 确认浪级：先识别最高级别趋势，再逐级细化

### 当前浪位判定流程

```
1. 确认大趋势方向（周线/日线）
2. 找到上一波完整的5浪推动或ABC调整
3. 根据当前价格相对于上一波的位置判断当前浪位
4. 用斐波那契比例验证浪位假设
5. 结合五色青龙信号确认动量方向
```

## 四、89日均线策略

### 核心规则

- **持仓条件**：价格站上89日均线 → 持有
- **止盈条件**：价格跌破89日均线 → 止盈离场
- **均线方向**：89日均线向上倾斜 → 趋势偏多；向下倾斜 → 偏空

### 操作细则

| 状态 | 价格与89MA关系 | 89MA方向 | 操作 |
|------|---------------|---------|------|
| 强势持仓 | 价格 > 89MA | 向上 | 坚定持有，可加仓 |
| 中性持仓 | 价格 > 89MA | 走平/向下 | 减仓或设紧止损 |
| 观望 | 价格 < 89MA | 向上 | 等重新站上再入场 |
| 离场 | 价格 < 89MA | 向下 | 清仓或止盈 |

### 突破确认

- 价格从上向下穿越89MA：当日收盘确认跌破才执行止盈
- 价格从下向上穿越89MA：连续2日站稳89MA上方方可确认突破
- 假突破过滤：穿越幅度 < 1% 且当日量比 < 0.8 视为假突破

## 五、筹码集中度90监控

### 定义

- **筹码集中度90** = 市场中90%持仓成本分布的区间宽度 / 当前股价 × 100%
- 数值越小，筹码越集中；数值越大，筹码越分散

### 买卖条件

| 条件 | 阈值 | 操作 |
|------|------|------|
| **买入信号** | 集中度90 < 15% | 筹码高度集中，主力控盘，可买入 |
| **卖出信号** | 集中度90 > 25% | 筹码分散，主力出货迹象，应卖出 |

### 解读

- **集中度 < 10%**：极度集中，主力高度控盘，爆发力强但流动性风险大
- **集中度 10%-15%**：集中，适合买入区域
- **集中度 15%-25%**：中性，持仓观望
- **集中度 > 25%**：分散，触发卖出条件
- **集中度 > 35%**：极度分散，无主力关照，不宜持有

### 与量价配合判断

- 集中度从高位（>25%）快速下降到低位（<15%）+ 赤红信号 → 主力吸筹完毕，最佳买点
- 集中度从低位（<15%）快速上升到高位（>25%）+ 黄色信号 → 主力出货，果断卖出

## 六、WR威廉指标（Williams %R，超买超卖温度表）

由 Larry Williams 于 1973 年提出，衡量**当前收盘价在最近 N 天价格区间里的位置**——是贴着近期高点（热）还是贴着近期低点（冷）。

### 公式

```
WR = (N日最高价 − 当日收盘价) / (N日最高价 − N日最低价) × 100
```

取值 0–100：
- **趋近 0** → 收盘价贴近 N 日最高点 → **超买**（热，可能回落）
- **趋近 100** → 收盘价贴近 N 日最低点 → **超卖**（冷，可能反弹）

### 双线设置

| 线 | 周期 | 特征 |
|----|------|------|
| 短期WR | 6日 | 更灵敏，先反应短线动量 |
| 长期WR | 10日 | 更平滑，减少噪音，作为主判定线 |

### 超买超卖判定（以长期WR为主）

| WR值 | 区域 | 含义 | 操作倾向 |
|------|------|------|---------|
| ≥ 80 | 超卖 | 价格贴近近期低点 | 偏多，关注反弹/抄底 |
| ≤ 20 | 超买 | 价格贴近近期高点 | 偏空，注意回落/止盈 |
| 50–80 | 偏冷 | 中性区但倾向超卖 | 可关注低吸机会 |
| 20–50 | 偏热 | 中性区但倾向超买 | 注意追高风险 |

### 金叉 / 死叉

- **金叉**：短期WR(6日) 上穿 长期WR(10日) → 短线动量转强，偏多信号
- **死叉**：短期WR(6日) 下穿 长期WR(10日) → 短线动量转弱，偏空信号
- 交叉信号仅作辅助确认，不单独作为买卖依据

### 与 KDJ 的关系

WR = 100 − RSV（KDJ 的基础值），数学上与 KDJ 完全对偶。一个看"从顶往下"，一个看"从底往上"，本质一样。选择 WR 而非 KDJ 的原因：WR 刻度直觉（0=最热、100=最冷），与"温度表"隐喻一致，便于与支撑/阻力共振判断。

### 使用注意事项

1. **单独使用易钝化**：单边上涨时 WR 长期卡在 <20 超买区却还在涨；单边下跌时卡在 >80 超卖区却还在跌。**必须配趋势/支撑一起看**
2. **共振优先**：
   - WR 进入超卖区 + 价格触及89MA/斐波那契支撑带 = 高胜率抄底区
   - WR 进入超买区 + 价格触及阻力带（前高/扩展位）= 高胜率逃顶区
3. **中性区微调**：WR 在 50–80（偏冷）时偏多但未极端，可关注低吸；WR 在 20–50（偏热）时偏空但未极端，注意追高

## 七、综合信号对齐框架

将以上六个维度按权重整合，形成最终的买卖决策：

| 维度 | 权重 | 多头条件 | 空头条件 |
|------|------|---------|---------|
| 五色青龙 | 23% | 赤红/橙色连续 | 黄色/绿色连续 |
| 89日均线 | 23% | 价格 > 89MA | 价格 < 89MA |
| 波浪位 | 18% | 推动浪初期（浪1/浪3） | 浪5末端或C浪 |
| 黄金分割 | 13% | 回调至38.2%/50%获支撑 | 反弹至61.8%遇阻 |
| 筹码集中度 | 13% | 集中度90 < 15% | 集中度90 > 25% |
| WR威廉指标 | 10% | WR≥80超卖区或金叉 | WR≤20超买区或死叉 |

### 信号强度分级

- **强买入（≥80分）**：5项及以上满足多头条件
- **弱买入（60-79分）**：3-4项满足多头条件
- **中性（40-59分）**：多空条件各半或信号不明确
- **弱卖出（20-39分）**：3-4项满足空头条件
- **强卖出（<20分）**：5项及以上满足空头条件

## 八、数据获取

分析需要以下数据字段（日线级别，建议至少120个交易日）：

- 日期、开盘价、最高价、最低价、收盘价、成交量
- 筹码集中度90（如数据源不直接提供，可通过公开数据估算）
- 如分析指数：成分股权重和自由流通市值

### 推荐数据源

- 通达信（tdx-connector）：行情数据、财务数据
- eastmoney（东方财富）：筹码分布数据
- AKShare（开源）：综合金融数据接口
