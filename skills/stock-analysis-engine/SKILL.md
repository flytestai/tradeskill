# 股票分析引擎（Stock Analysis Engine）

> 核心理念：**多周期定位定方向，多维共振定机会，量化评分定决策。**
> 铁律：**不幻想（标数据来源与时间）、不讨好（该清仓就说）、不摇摆（结论与评分一致）、可校验（每个结论附可验证指标）。**

本引擎去重融合七套技能，形成以下 8 个维度。分析时按需组合维度，维度越多共振，结论置信度越高。

---

## 维度 1：多周期定位（铁三角）

**月线定方向 → 周线定节奏 → 日线定点位。**

| 周期 | 作用 | 依据 |
|------|------|------|
| 月线 | 定大方向/浪级 | 当前处于推动相（①②③④⑤）还是调整相（A-B-C） |
| 周线 | 定节奏/结构 | 确认主驱动浪或调整浪结构 |
| 日线 | 定点位/进出 | 精确买卖点、支撑压力、失效位 |

三层共振 = 最大机会；三层背离 = 最大风险。

## 维度 2：波浪理论（三套合并后的完整体系）

### 八浪循环
完整循环 = 5 浪推动 + 3 浪调整（①②③④⑤ + A-B-C）。

### 驱动浪（Motive）
- **标准推动浪（Impulse）**：五大铁律——① 2 浪不破 1 浪起点；② 3 浪非最短；③ 4 浪不与 1 浪重叠（无延伸时）；④ 五子浪内部须有次级五浪结构；⑤ 1/3/5 浪中必有一浪延伸。
- **延伸浪（Extension）**：3 浪延伸最常见（≈1 浪的 1.618 倍或更多）；5 浪延伸次之；1 浪延伸最少。
- **斜截浪（Diagonal）**：领导型（①/A 浪，5-3-5-3-5）；终结型（⑤/C 浪末端，3-3-3-3-3，之后通常急反转）。

### 调整浪（Corrective）
| 形态 | 结构 | 特征 |
|------|------|------|
| 锯齿形 Zigzag | 5-3-5 | 快速深幅，B 回撤 A 的 38.2%~50% 内 |
| 平台形 Flat | 3-3-5 | B 接近/超越 A 起点，C 等于或略超 A |
| 扩张平台 Expanded | 3-3-5 | B 超 A 起点，C 超 A 终点 |
| 三角形 Triangle | 3-3-3-3-3 | 仅出现于 ④/B 浪，之后有"喷射" |
| 复杂调整 WXY | 组合 | 双重锯齿/双重三/三重三，X 浪连接 |

### 特殊形态
- **失败第五浪（Truncated Fifth）**：5 浪不破 3 浪高点，随后调整幅度通常较大。
- **B 浪陷阱（Bull Trap）**：B 浪内部为 3 浪结构、放量特征弱，常被误判为新推动浪。
- **交替原则**：②④ 浪在形态/深度/复杂度上交替（简单锯齿 ↔ 平台/三角）。

### 斐波那契
- 2 浪回撤：1 浪的 38.2%/50%/61.8%（最常见 61.8%）
- 3 浪目标：1 浪的 1.618×/2.618×（自 2 浪底量起）
- 4 浪回撤：3 浪的 23.6%/38.2%
- 5 浪目标：=1 浪长，或 ①~③ 区间的 0.618×
- 锯齿 C = A 或 1.618×A；平台 C = A 或 1.236×/1.382×A
- 时间比例：1:1、1:1.618、1:2.618（辅助验证，不否定形态）

### 研判五步
1. 划大周期浪级 → 2. 识别主形态 → 3. 核对形态/比例/时间 → 4. 预判后续走向（**主计数 + 至少一个备选计数 + 失效位**）→ 5. 划支撑压力。

### 形态优先原则
形态优先于计数；保持多方案；不跳级（自下而上逐级确认）；以形态盖时间。

### RSI 背离确认（辅助）
RSI 顶背离/底背离与波浪末端共振时，转折信号增强。

## 维度 3：量价与技术指标

### 五色青龙量价（量在价先）
- 🔴赤红 + 高量比 = 主力强势介入，可积极参与
- 🟢绿色 + 低量比 = 自然回调，不必恐慌
- 🟡黄色 + 高量比 = 放量下跌，提高警惕
- 单日信号仅参考，连续 2 天同色为有效信号

### 89 日均线纪律
- 站上 89MA → 持有（均线向上为强势持有）
- 跌破 89MA → 止盈（收盘确认跌破才执行）
- 均线向下且价在下方 → 清仓/不买
- 跌破后快速收回 + 量比<0.8 → 疑似假跌破

### 筹码集中度 90
- <15% 买入（筹码集中、主力控盘）；<10% 爆发力强但防流动性风险
- >25% 卖出（筹码分散、主力出货）
- 集中度从高位快速下降 + 赤红 = 最佳买点；从低位快速上升 + 黄色 = 果断卖出

### WR 威廉指标（超买超卖温度表）
- WR≥80 超卖（偏多，若叠加 89MA/斐波那契支撑带 = 共振买点）
- WR≤20 超买（偏空，分批止盈，不追高）
- 短期 WR(6) 上穿长期 WR(10) = 金叉（转强）；下穿 = 死叉（转弱）
- 单边行情 WR 易钝化，必须与趋势/支撑结合

### 黄金分割（斐波那契回调/扩展）
回调位 23.6/38.2/50/61.8/78.6%；扩展位 1.618/2.618。

### MACD 背离
顶背离（价创新高 MACD 走低）= 逃顶信号；底背离 = 抄底信号；量价背离辅助判断出货/吸筹。

## 维度 4：智能资金（主力行为）

### 威科夫六阶段
- **吸筹**：Spring（弹簧探底）→ SOS（强势信号）→ 主升浪
- **派发**：UTAD（上冲回落）→ SOW（弱势信号）→ 下跌

### SMC 智能资金概念
- **订单块（Order Block）**：主力建仓/派发的关键价格区
- **公允价值缺口（FVG）**：价格失衡区，常被回补
- **流动性清扫（Liquidity Sweep）**：扫止损后反向启动

### 筹码分布
获利盘比例、筹码集中度、主力成本区、穿透率 → 主力控盘判断。

## 维度 5：形态识别

- **缠论**：笔、线段、中枢；底部背驰/2 买确认（买入）、顶部背驰/1 卖确认（卖出）
- **谐波**：蝴蝶、蝙蝠、加特利等形态，D 点完成点
- **经典形态**：头肩顶/底、三角形、整理形态，突破关键压力/支撑确认

## 维度 6：基本面

### 排雷清单（满足任一条件 → 谨慎/回避）
近三年净利润为负；应收账款异常增长（>营收增速 2 倍）；存货周转天数持续上升；经营现金流连续为负；商誉占净资产 >50%；大股东高比例质押；监管处罚/立案调查；财报非标意见。

### 估值与质量
- **杜邦三因子**：ROE = 净利率 × 资产周转率 × 权益乘数（判断 ROE 来源质量）
- **DCF 内在价值**：5 年 FCF 预测 + 永续增长 + WACC 折现；安全边际 ≥30% 为显著低估
- **相对估值**：PE 历史分位、PEG（<1 低估）、EV/EBITDA 跨行业比较
- **财务健康**：现金流质量（OCF/净利润）、FCF、负债率、利息覆盖率
- **波特五力**：竞争强度、进入壁垒、替代品、供应商/客户议价能力

## 维度 7：量化评分

### 六维共振评级（基本面 > 消息面 > 技术面）
| 星级 | 含义 | 操作 |
|------|------|------|
| 6 星 | 完美共振 | 强烈买入 |
| 5 星 | 高度共振 | 积极买入 |
| 4 星 | 较强共振 | 逢低买入 |
| 3 星 | 中性共振 | 观望为主 |
| 2 星 | 偏弱共振 | 谨慎观望 |
| 1 星 | 弱共振 | 回避/卖出 |

权重参考：基本面 30% + 消息面 20% + 技术面（波浪/缠论/谐波/形态）各约 10%~15%。

### Alpha101 因子（动量/价值/成长/质量/资金流）
- 动量：区间涨幅/超额收益
- 价值：EP（盈利收益率）/BP（账面价值比）
- 成长：营收增速、ROE 趋势
- 质量：现金流、毛利率稳定性
- 资金流：大单净流入、北向、融资余额

### 综合评分（0-100）
- ≥75 强烈买入（HIGH）；60-75 温和买入（MEDIUM）；40-60 观望；<40 减仓；基本面恶化或派发 Phase C/D 强烈卖出（HIGH）。

## 维度 8：操作体系

### 交易纪律（8 条）
1. 三层共振才重仓，背离减仓
2. 跌破 89MA 收盘确认止盈，不抱侥幸
3. 筹码集中度 >25% 果断离场
4. WR 超买 + 阻力带 = 止盈；WR 超卖 + 支撑带 = 低吸
5. 单板块仓位设上限（S 级 25% / A 级 20% / B 级 10% / C 级 5%）
6. 单日最大回撤 5% 强制风控
7. 不碰明确黑名单品种（如军工/传媒/游戏/次新，按用户画像）
8. 结论必须与评分一致，不因持仓偏袒

### 仓位与止损
- 依据六维共振星级定仓位；止损位取关键支撑/失效位下方；目标位取斐波那契扩展位/前高。

### 板块轮动
宏观（流动性/信用/政策）→ 中观（产业景气/盈利周期）→ 微观（资金/情绪/形态），自上而下判断轮动节奏。

### 每日复盘
盘前：隔夜消息 + 关键位 + 预案；盘后：量价、板块涨跌、信号是否兑现、修正浪型计数。
